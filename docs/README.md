# Documentação de desenvolvimento

Esta pasta concentra os materiais detalhados usados durante o desenvolvimento
e o estudo do projeto. O `README.md` da raiz permanece focado na apresentação
da API e em sua inicialização rápida.

## Planejamento

- [Plano detalhado da primeira versão](plano-v1.md): escopo, arquitetura, modelo
  de dados, contratos HTTP e etapas com tarefas e critérios de aceitação para
  desenvolvimento por uma pessoa júnior ou estagiária. Descreve trabalho futuro,
  não funcionalidades já entregues.

## Guias

- [Domínio e visualizações](domain-guide.md): criação de datasets, estatísticas,
  alterações, validações e geração de gráficos.
- [Banco de dados e migrações](database-and-migrations.md): PostgreSQL, Docker,
  Alembic, volumes e comandos executados dentro e fora dos containers.

Os exemplos refletem o comportamento atual do código e devem ser atualizados
junto das funcionalidades correspondentes.
