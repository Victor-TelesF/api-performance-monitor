## Planejamento

O [plano da primeira versão](plano-v1.md) descreve o escopo futuro de
monitoramento automático, os contratos propostos e as etapas de implementação.
As tarefas planejadas não representam funcionalidades já entregues.

Os exemplos refletem o comportamento atual do código e devem ser atualizados
junto das funcionalidades correspondentes.
